1.6.1
- Changelog migrated to standalone file (changelog.txt)
- Version overlay now opens changelog.txt instead of in-app panel

1.6.0
- Batch edit — change priority, status, list, or due date on multiple selected tasks at once
- Drag tasks onto sidebar lists to move them between lists
- Statistics panel in Settings — completion rates, priority breakdown, per-list progress, and 14-day activity heatmap
- Keyboard shortcuts cheatsheet — press ? or Ctrl+/ to open
- Detail panel now scrolls back to the top when switching between tasks
- Fixed undo support for batch complete and batch delete
- Fixed drag-and-drop reorder within the same list

1.5.0
- Multi-select & batch actions — select multiple tasks and complete or delete them in bulk
- Due-date notifications with browser push alerts and an overdue badge in the tab title
- Calendar view — see your tasks on a month grid, click a day to jump to it
- Undo history (Ctrl+Z) — undo the last completed task, deleted list, skipped or paused action
- Saved filter presets — save your current filter/sort combo and recall it from a dropdown
- Recurring end date — set a date or count at which a recurring task stops repeating
- Task links — attach URLs to tasks and open them from the detail panel or task row
- Task logbook — keep a dated journal of notes, edits, and completions per task
- Keyboard navigation — use Arrow keys to move through the task list, Enter to open, Delete to remove
- Mobile long-press context menu — hold a task on touch devices to quick-action it
- When changing a task to In Progress or Paused, you're now asked whether to remove its due date
- Confirmation dialogs now have descriptive titles and context-specific buttons
